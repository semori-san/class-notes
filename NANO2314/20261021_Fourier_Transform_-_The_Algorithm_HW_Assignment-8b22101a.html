3. The Fourier transform by computer (4 points)

The Python script at https://tinyurl.com/N2314-FT-algorithm-py does Problem 2(a)–(c) on real data. Its function test_frequency(f) takes one reference frequency f in kHz, multiplies the signal by the reference, adds up the area under the product, and returns the amplitude of the signal at that frequency, in nm. (It uses a sine and a cosine reference and combines them into a “matched” sine that lines up with the signal, so it finds a vibration whatever its phase; see lecture section 4. Amplitude = 2 × (matched area) / Twindow, where Twindow = 500 µs is the length of the record.)

To start: download the script, paste it into a Google Colab code cell, and run it. It loads the data and makes the two example plots below.

Data: 261026-bimodal_AFM-data-v2.csv (https://tinyurl.com/N2314-AFM-data-v2), a new 500 µs recording of a bimodal AFM cantilever like the last homework’s (time_us in µs, deflection_nm in nm, 5000 points). Use this file, not the last homework’s.

Script output at 68 kHz (left) and 72 kHz (right). At 68 kHz the positive (green) and negative (red) areas nearly cancel: amplitude 2.05 nm. At 72 kHz the matched product is positive throughout: amplitude 18.7 nm.
