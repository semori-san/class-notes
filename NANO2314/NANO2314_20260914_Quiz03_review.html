  1. 1. (1 pt) Exponential growth z=Certz = Ce^{rt} (or decay z=Ce−rtz = Ce^{-rt}) of some quantity zz versus time tt would appear linear when you plot

    1. ln⁡z\ln z vs ln⁡t\ln t
    2. zz vs tt
    3. ln⁡z\ln z vs tt
    4. zz vs ln⁡t\ln t
    5. eze^{z} vs tt
    Solution for question 1

    Correct answer: C. ln⁡z\ln z vs tt

    Why: To straighten an exponential, undo the exponential: take the natural log of both sides.

    ln⁡z=ln⁡C+rt(or ln⁡z=ln⁡C−rt for decay).\ln z = \ln C + rt \qquad (\text{or } \ln z = \ln C - rt \text{ for decay}).

    That is the equation of a straight line, y=b+mxy = b + mx, once you plot y=ln⁡zy = \ln z against x=tx = t: slope ±r\pm r, intercept ln⁡C\ln C. Only the vertical axis gets the log — this is a semi-log plot.

    Watch out: choice A (ln⁡z\ln z vs ln⁡t\ln t) is a log–log plot, which straightens a power law z=Ctrz = Ct^{r}, because ln⁡z=ln⁡C+rln⁡t\ln z = \ln C + r\ln t — the wrong family of functions. Choice B is the raw data, and the curvature of an exponential on linear axes is the reason we linearize at all. Choice D puts the log on the wrong variable; it straightens z=aln⁡t+bz = a\ln t + b. Choice E exponentiates a second time, which bends the curve even more.

  2. 2. (1 pt) In the equations in Question 1, the value of the characteristic rr is

    1. positive, and has a unit of time
    2. positive, and has a unit of inverse time
    3. negative, and has a unit of inverse time
    4. positive or negative, and has a unit of time
    5. real or complex, and has a unit of time
    Solution for question 2

    Correct answer: B. positive, and has a unit of inverse time

    Why: Two separate facts, and the answer needs both.

    The sign. Growth and decay are already written into the formulas as +rt+rt and −rt-rt, so rr itself is a positive number that says how fast.

    The unit. You can only raise ee to a pure number, so the exponent rtrt must be dimensionless. If tt is in seconds, rr has to be in s−1\text{s}^{-1}:

    [r]=1[t].[r] = \frac{1}{[t]}.

    Watch out: choice A gets the sign right but gives rr a unit of time, which would make rtrt a time squared inside an exponent. Choice C gets the unit right, but a negative rr in Ce−rtCe^{-rt} would flip decay into growth — the minus sign is already there. Choice D misses on both counts, and choice E introduces complex rr, which describes oscillation rather than growth or decay (and still has the wrong unit).

  3. 3. (1 pt) From the slope of the linear graph in Question 1, you can quantify

    1. CC
    2. ln⁡C\ln C
    3. the time at which z=0z = 0
    4. the magnitude of rr
    5. your instructor’s salary
    Solution for question 3

    Correct answer: D. the magnitude of rr

    Why: Read it straight off the linearized equation from Question 1:

    ln⁡z=ln⁡C±rt.\ln z = \ln C \pm rt.

    The coefficient of tt is the slope: +r+r for growth, −r-r for decay. Either way its size is rr. So the slope of a semi-log plot measures the growth or decay rate directly — which is exactly why this plot is so useful for real data.

    Watch out: choices A and B mix up slope and intercept. The intercept of the line is ln⁡C\ln C, and CC itself comes from C=einterceptC = e^{\text{intercept}} — neither is the slope. Choice C describes a point that does not exist: an exponential never reaches zero, and ln⁡z\ln z is undefined at z=0z = 0. Choice E is, alas, not recoverable from any plot.

  4. 4. (1 pt) An object sits in surroundings at ambient temperature TaT_a. Its temperature at time tt is T=Ce−rt+TaT = Ce^{-rt} + T_a. What is the physical meaning of CC?

    1. the characteristic growth or decay rate
    2. the initial measured temperature of the object
    3. the ambient (surrounding) temperature
    4. the initial cooling rate, dT/dtdT/dt at t=0t = 0
    5. none of the above
    Solution for question 4

    Correct answer: E. none of the above

    Why: Evaluate the formula at the one time where the exponential is easy, t=0t = 0, where e0=1e^{0} = 1:

    T(0)=C+Ta⇒C=T(0)−Ta.T(0) = C + T_a \quad\Longrightarrow\quad C = T(0) - T_a.

    So CC is the initial temperature difference between the object and its surroundings — positive for an object that starts hotter and cools, negative for one that starts colder and warms. None of choices A–D says that. The term Ce−rtCe^{-rt} is that difference shrinking away as the object settles toward TaT_a.

    Watch out: choice B is the tempting one: at t=0t = 0 the object is at its initial temperature, but T(0)=C+TaT(0) = C + T_a, so CC equals the initial temperature only if Ta=0T_a = 0. Choice A describes rr, which has units of inverse time, while CC is a temperature. Choice C is TaT_a, the value TT approaches as t→∞t \to \infty. Choice D is dT/dtdT/dt at t=0t = 0, which works out to −rC-rC: it involves CC but carries an extra factor of −r-r and has units of temperature per time.

  5. 5. (1 pt) If you selected “none of the above” for Question 4, write down what you believe to be the correct physical meaning of CC, and explain.

    Solution for question 5

    Meaning: C=T(0)−TaC = T(0) - T_a, the initial temperature difference between the object and its surroundings.

    Explanation — set t=0t = 0: since e0=1,e^{0} = 1,

    T(0)=Ce0+Ta=C+Ta⇒C=T(0)−Ta.T(0) = Ce^{0} + T_a = C + T_a \quad\Longrightarrow\quad C = T(0) - T_a.

    An equally good explanation: rearrange the model as

    T−Ta=Ce−rt.T - T_a = Ce^{-rt}.

    The left side is how far the object is from the surrounding temperature at time tt. At t=0t = 0 that gap is exactly CC, and as t→∞t \to \infty it decays to 00 as the object reaches TaT_a.

    Sanity check with units: TT and TaT_a are temperatures, and e−rte^{-rt} is a pure number, so CC must be a temperature too — which rules out reading it as a rate.

  6. 6. (4 pts) You are given

    ert=∑n=0∞(rt)nn!.e^{rt} = \sum_{n=0}^{\infty} \frac{(rt)^{n}}{n!}.

    1. (1.5 pts) Write erte^{rt} as a series (a sum of polynomial terms) from n=0n = 0 to n=3n = 3. You should thus have four terms.

      Solution — part (a) of question 6

      Write out the n=0,1,2,3n = 0, 1, 2, 3 terms, remembering that 0!=10! = 1 and (rt)0=1(rt)^{0} = 1:

      ert≈(rt)00!+(rt)11!+(rt)22!+(rt)33!=1+rt+r2t22+r3t36.e^{rt} \approx \frac{(rt)^{0}}{0!} + \frac{(rt)^{1}}{1!} + \frac{(rt)^{2}}{2!} + \frac{(rt)^{3}}{3!} = 1 + rt + \frac{r^{2}t^{2}}{2} + \frac{r^{3}t^{3}}{6}.

      Two places people slip: the power applies to the whole product rtrt, so rr is squared and cubed along with tt; and 3!=3⋅2⋅1=63! = 3 \cdot 2 \cdot 1 = 6, not 33. Leaving the factorials unevaluated, as 2!2! and 3!3!, is perfectly fine.

    2. (1.5 pts) Take the derivative of your series from (a) with respect to time tt.

      Solution — part (b) of question 6

      Differentiate term by term. Here rr is a constant, so only the powers of tt change — each drops by one, and the old exponent comes down as a factor:

      ddt[1+rt+r2t22+r3t36]=0+r+2r2t2+3r3t26=r+r2t+r3t22.\frac{d}{dt}\left[1 + rt + \frac{r^{2}t^{2}}{2} + \frac{r^{3}t^{3}}{6}\right] = 0 + r + \frac{2r^{2}t}{2} + \frac{3r^{3}t^{2}}{6} = r + r^{2}t + \frac{r^{3}t^{2}}{2}.

      Quick check: every term’s power of tt went down by one, the constant term vanished, and rr was never differentiated. If a power of tt went up, or a power of rr changed, something went wrong.

    3. (1 pt) Based on (b), make a case that ddtert=rert\dfrac{d}{dt}\,e^{rt} = r\,e^{rt}.

      Solution — part (c) of question 6

      Factor rr out of the derivative you found in (b):

      r+r2t+r3t22=r[1+rt+(rt)22!].r + r^{2}t + \frac{r^{3}t^{2}}{2} = r\left[\,1 + rt + \frac{(rt)^{2}}{2!}\,\right].

      The bracket is exactly the beginning of the series for erte^{rt} from (a). So differentiating the series gave back rr times the series: ddtert=rert\dfrac{d}{dt}e^{rt} = r\,e^{rt}.

      Why the bracket is one term short: (a) stopped at n=3n = 3, and differentiating removes the constant term. Had you kept the n=4n = 4 term, (rt)4/4!(rt)^{4}/4!, its derivative would be r(rt)3/3!r(rt)^{3}/3!, supplying the missing term. In general,

      ddt(rt)nn!=nrntn−1n!=r(rt)n−1(n−1)!,\frac{d}{dt}\,\frac{(rt)^{n}}{n!} = \frac{n\,r^{n}t^{n-1}}{n!} = r\,\frac{(rt)^{n-1}}{(n-1)!},

      so each term becomes rr times the one before it, and the full infinite series reproduces itself times rr.

      Note that the question asks for a case built from (b). Quoting the chain rule states the result instead of showing it.

  7. 7. (1 pt) Extra credit. Make a case that ∫ertdt=1rert+K\displaystyle\int e^{rt}\,dt = \frac{1}{r}\,e^{rt} + K, where KK is some constant.

    Solution for question 7

    Route 1 — run the derivative backwards. Integration undoes differentiation, so check that the proposed answer differentiates back to erte^{rt}, using the result of Question 6(c):

    ddt[1rert+K]=1r⋅rert+0=ert.✓\frac{d}{dt}\left[\frac{1}{r}e^{rt} + K\right] = \frac{1}{r}\cdot r\,e^{rt} + 0 = e^{rt}. \;\checkmark

    The constant KK is allowed to be anything, because every constant has derivative 00 — adding one gives another function with the same derivative.

    Route 2 — integrate the series term by term.

    ∫∑n=0∞(rt)nn!dt=∑n=0∞rntn+1(n+1)n!=1r∑n=0∞(rt)n+1(n+1)!=1r(ert−1)+K′.\int \sum_{n=0}^{\infty} \frac{(rt)^{n}}{n!}\,dt = \sum_{n=0}^{\infty} \frac{r^{n}t^{n+1}}{(n+1)\,n!} = \frac{1}{r}\sum_{n=0}^{\infty} \frac{(rt)^{n+1}}{(n+1)!} = \frac{1}{r}\left(e^{rt} - 1\right) + K'.

    The re-indexed sum is the series for erte^{rt} missing only its first term, 11. The leftover −1/r-1/r is a constant, so it is absorbed into KK, giving 1rert+K\frac{1}{r}e^{rt} + K.

    Route 3 — substitution. Let u=ertu = e^{rt}, so du=rertdtdu = r\,e^{rt}\,dt and ertdt=du/re^{rt}\,dt = du/r. Then ∫ertdt=1r∫du=1ru+K=1rert+K\int e^{rt}\,dt = \frac{1}{r}\int du = \frac{1}{r}u + K = \frac{1}{r}e^{rt} + K.

    Stating the formula, even with a correct remark about KK, is not yet a case for it — one of these routes has to be carried out.
